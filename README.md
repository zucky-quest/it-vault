# It Vault

このリポジトリは、技術知識・学習記録・転職活動・クリッピングを一つの Obsidian Vault として管理するためのデータベースです。

## 目的

- 日々の学びや気づきを残す
- 資格勉強・転職活動・業務知見を整理する
- 技術ブログや Web クリッピングを再利用しやすくする
- 画像や添付ファイルを一元管理する

## ディレクトリ構成

[ディレクトリ構造の設計書](./00-index/docs/0-design/dir-structure.md) を参照してください。

## 主な用途

### 01-journal

- 日々の振り返り
- 明日の Todo
- 学んだこと・気づき
- 1日1ファイル形式で記録

### 02-projects

- 資格の勉強記録
- 転職準備資料
- 自己PR・職務経歴書の草案
- 学習メモの整理

### 03-work

- 技術ブログや Qiita 向けの執筆
- 業務での知見や実装メモ
- 文章化したアウトプットの保管

### 04-clippings

- 実務で参考にした記事
- 技術調査メモ
- ブログや資料の引用保存

### 05-assets

- 画像
- スクリーンショット
- 図や図解
- 文章以外の添付ファイル

## 運用ルール

- 新しいメモは用途に応じて適切なディレクトリへ配置する
- その日の記録は `01-journal` に残す
- 学習や転職準備は `02-projects` にまとめる
- 重要な技術記事は `04-clippings` から `03-work` へ発展させる
- 画像やスクリーンショットは `05-assets` に保存し、本文から参照する

## 使い方のイメージ

- 何かを学んだ → `01-journal` にメモ
- その知識を深める → `02-projects` または `03-work` に整理
- 参考にした記事 → `04-clippings` に保存
- 図や画像が必要 → `05-assets` に保管

## 補足

この Vault は、個人の知識整理とアウトプットを継続しやすくすることを目的にしています。定期的に整理し、過去のノートを再利用できるように保つと、学習の蓄積がしやすくなります。
