## 設計方針

- 情報の保管場所を役割ごとに分離し、検索性と再利用性を保つ
- 設定の正本（SSOT: Single Source of Truth）は、生成先ではなくソース側で管理する
- 生成可能な設定は手編集せず、定義ファイルから再生成する
- ツール固有の設定は、共通設定から各ツールの形式へ変換して配備する
- 変更内容は Git で管理し、生成物との不整合を検査できる状態にする
