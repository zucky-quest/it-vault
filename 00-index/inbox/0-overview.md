# Vault Overview

この Vault は、学習・実務・転職・アウトプットを一つの場所にまとめて管理するための、Obsidian ベースの知識管理スペースです。

## 目的

- 学んだことを継続的に記録する
- 日々の振り返りと成長の軌跡を残す
- 資格勉強や転職活動を整理して進捗を可視化する
- 技術ブログや記事執筆の材料を溜める
- 参考にした Web 記事や画像を再利用しやすく保管する

## この Vault の考え方

この Vault の価値は、情報を「ただ保存する」だけでなく、後で探しやすく、再利用しやすくすることです。

- 一般的なメモは `01-journal` に残す
- 学習やキャリア形成のテーマは `02-projects` にまとめる
- 発信する知識や成果物は `03-work` で管理する
- 参考記事や調査メモは `04-clippings` に保管する
- 図や画像などの添付ファイルは `05-assets` へ置く

## 管理の基本ルール

- すべての情報は「後で自分が見返せる」状態を意識する
- インプットとアウトプットを分けて管理する
- まだ整理できていないメモは `00-index/inbox` に一時保管する
- 画像やスクリーンショットは本文に埋め込むのではなく参照として扱う

## 期待する使い方

- 学びを記録して、知識を積み上げる
- 調べた情報を再利用して、実務や執筆に活かす
- 転職活動や資格勉強の軌跡を残す
- すべての情報を自分の「ナレッジベース」として扱う

## 価値

これは単なるメモ帳ではなく、将来の自分が使える知識の土台です。半年後・1年後に振り返ったときに、過去の学びが「自分の資産」として活きる状態を目指しています。
